# PrivacyLib runtime provenance

The unmodified JavaScript decision router and eleven GDPR Rego modules in this directory were copied from https://github.com/CS-UCY-SEIT-lab/PrivacyLib-REGO for this integration. The router filename uses .cjs so both CommonJS and ES-module host applications can import the same runtime. Host-specific adapters and synthetic policy configuration are one level above this directory.
